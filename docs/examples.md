# Examples

These recipes combine the data and plotting APIs for common analysis tasks.
Each includes its setup and states which output files it needs. Replace
`input` and `Output` with your run's paths.

| Goal | Recipe |
| --- | --- |
| Compute a field and compare its map with a mean profile | [Magnetic magnitude and profile](examples/magnetic-field.md) |
| Plot a maximum over time and export it to CSV | [Field history](examples/time-history.md) |
| Compare magnetic components or spatial directions | [Power spectra](examples/spectra.md) |

To try fields and particle tracks without your own output, open the
[example notebook](https://github.com/AstroplasmasUChicago/dhybridrpy/blob/main/examples/examples.ipynb)
from the repository's `examples/` directory. It uses the bundled sample data.
